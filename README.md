# Plainly Given

Static marketing site for Plainly Given donation receipt and contribution statement templates.

Live: https://spartan3055.github.io/plainly-given/

- Edit HTML/CSS directly (built from a generator script kept outside this repo).
- Binary files can be committed as base64 under `b64src/<path>.b64`; the Publish workflow decodes them and mirrors `main` to `gh-pages` (the GitHub Pages source).
- Buy buttons use the placeholders `GUMROAD_GENERATOR_URL` and `GUMROAD_PACK_URL`.

Not tax or legal advice. Templates are not official IRS forms.
